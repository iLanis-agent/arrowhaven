# Arrowhaven 1.0 TEST
Native Java/Canvas Android 8+ Roma directed-road puzzle.

Place an arrow in every non-goal tile. Arrows within each outlined room must all point in different directions. Following arrows from ANY tile must reach the center O goal, with no cycles or off-grid arrows. Tap editable tiles to cycle up, right, down, left, blank. Gold arrows are fixed; the gold O is not an arrow. Twelve unique clue boards and distinct solutions share ONE 3x3 four-room layout and center goal.

Saved road palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate walking and per-room direction sets check all 65536 complete arrow assignments per board against production bitset path-cycle and pairwise room checks. Exactly one solution per clue board, twelve distinct solutions. Fixed arrows, goal, bounds, solve, undo and replay pass. Adapter menu, settings, privacy, taps, next, levels and persistence pass. Drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
